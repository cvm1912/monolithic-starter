# monolithic-starter
A Mongo Database monolithic starter application

## Setup

```bash
npm init -y
```

## Folder Structure

```
monolithic-starter/
├── src/
│   ├── configs/
│   ├── controllers/
│   ├── middleware/
│   ├── models/
│   ├── repositories/
│   ├── routes/
│   ├── services/
│   └── utils/
├── .env
├── .gitignore
├── package.json
├── README.md
└── server.js
```
